One single-line office joke, written by a pure-stdlib Python program to
`/output/entry.txt`. The judge model compares jokes head to head; the
funniest takes the whole $2 prize.

## Entry

> The printer only jams when the deadline is today, which is how I know it
> reads my calendar better than my boss does.

## Run

```sh
python3 main.py
```

Writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
